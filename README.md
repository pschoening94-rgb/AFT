# TwitchTB - Eigenes TizenBrew Modul

1. Erstelle ein kostenloses öffentliches Repo auf GitHub (z. B. `TwitchTB`).
2. Lade den Inhalt dieses ZIP-Ordners direkt ins Hauptverzeichnis (Root) hoch.
3. In TizenBrew auf deinem Fernseher: "Add GitHub Module" auswählen und eingeben:
   `DEIN_GITHUB_USERNAME/DEIN_REPO_NAME@main`

Fertig! TizenBrew lädt TwitchTB direkt aus deinem eigenen Repo mit voller 1440p-Unterstützung!
